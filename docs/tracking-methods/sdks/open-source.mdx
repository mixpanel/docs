Mixpanel's SDKs are open source. You can read the code that runs in your app or on your server, open issues, follow releases, and send pull requests on GitHub.

Mixpanel's platform is a hosted service. The SDKs send data to it, and the systems that ingest, store, and query that data aren't open source.

Each repository's full license text is linked in the tables below.
