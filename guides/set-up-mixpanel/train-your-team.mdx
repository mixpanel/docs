## Overview

This phase gets your teammates using Mixpanel. You'll help them learn the basics, find answers on their own, and build a first report. Teammates need access first. [Choose how people get access](/guides/set-up-mixpanel/configure-your-account#choose-how-people-get-access)

<Info>
  Most people won't read a long guide before they try something. Let teammates build a report that answers a question they care about early, then point them to learning resources.
</Info>

**Done when:**

- Teammates know the basics
- They can find answers on their own
- They create their first report

## Teach the basics

Help teammates learn how Mixpanel works and find answers on their own.

### Help teammates learn the basics

Point new users to an overview they can read or watch, and to courses if they want more. [Mixpanel Introduction](/guides/mixpanel-introduction) · [Mixpanel Fundamentals](https://university.mixpanel.com/student/path/3411736-mixpanel-fundamentals)

### Help teammates find answers

Show teammates how to ask Mixpanel's AI questions about your data. [Mixpanel Agent](/docs/mixpanel-agent)

## Build a first report

Help each teammate create a first report, and give them somewhere to find it.

### Help teammates build a report

Ask each teammate to pick a question they care about and build a report that answers it. [Reports](/docs/reports) · [Core Reports](/guides/guides-by-topic/core-reports)

### Put reports on a board

Save a few reports to a board that teammates can open first. [Boards](/docs/boards) · [Create Boards](/guides/guides-by-topic/core-reports/create-boards)
