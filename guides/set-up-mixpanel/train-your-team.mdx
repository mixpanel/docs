## Overview

This phase gets your teammates using Mixpanel. You'll help them learn the basics, find answers on their own, and build a first report. Teammates need access first. [Choose how people get access](/guides/set-up-mixpanel/configure-your-account#choose-how-people-get-access)

<Info>
  Most people won't read a long guide before they try something. Let teammates build a report that answers a question they care about early, then point them to learning resources.
</Info>

**Done when:**

- Teammates know the basics
- They can find answers on their own
- They create their first report

## Get teammates up to speed

Help teammates go from having access to using Mixpanel on their own.

### Put reports on a board

### Put reports on a board

A board gives teammates a place to start, so no one has to open Mixpanel to a blank page. Save a few reports that answer the questions you wrote down in Phase 1 to a board, then share it with your teammates. [Boards](/docs/boards) · [Sharing and Permission](/docs/boards/sharing-and-permission)

### Help teammates build a report

Once teammates have seen a board, have each one build a report from a question they care about. Starting with their own question shows them what Mixpanel can do for their work. [Reports](/docs/reports)

### Help teammates find answers

Once teammates are comfortable with the interface and can build a basic report, show them how to ask the Mixpanel Agent questions about your data. Teammates who've built reports can tell when an answer looks off. Have them open the report behind any answer and check it against the data before anyone acts on it. [Mixpanel Agent](/docs/mixpanel-agent)

### Help teammates learn the basics

Mixpanel Fundamentals walks through the core reports and how to use them, so teammates can analyze user behavior with confidence. Some people like to start with the course, and others like to get hands-on with a new tool first. Either works, so share it with each teammate and let them decide when to use it. [Mixpanel Fundamentals](https://university.mixpanel.com/student/path/3411734-mixpanel-fundamentals)
