The Insights API runs an Insights query that you describe in the request body and returns the results. You choose the metrics, the time range, and optional filters, breakdowns, and comparisons—the same building blocks as an Insights report.

To get the results of a report you've already saved, use [Query Saved Report](/reference/insights-query) instead.

## Endpoint

Send requests to the endpoint for your project's data residency:

| Data residency | URL |
| --- | --- |
| US (default) | `https://mixpanel.com/api/query/insights/query` |
| EU | `https://eu.mixpanel.com/api/query/insights/query` |
| India | `https://in.mixpanel.com/api/query/insights/query` |

For more about residency, see [EU Data Residency](/docs/privacy/eu-residency) and [India Data Residency](/docs/privacy/in-residency).

## Authentication

Authenticate with a [service account](/reference/service-accounts), sending its username and secret with HTTP basic authentication. Pass these query parameters:

- `project_id`: the ID of the project to query. Required.
- `workspace_id`: the ID of the data view to query. Include it if your project uses [data views](/docs/data-governance/data-views-and-classification).

## Request body

A request body has two required fields and four optional ones:

| Field | Required | What it holds |
| --- | --- | --- |
| `metrics` | ✅ | Up to 40 metrics to calculate: event, funnel, retention, cohort, or formula metrics. |
| `time` | ✅ | The time range, and optionally the unit that splits it into a time series. |
| `filters` | ❌ | Up to 10 filters that apply to every metric. |
| `breakdowns` | ❌ | Up to three breakdowns by property value or cohort membership. |
| `time_comparison` | ❌ | An earlier period to run the same query over. |
| `lift_comparison` | ❌ | Reports each result as a change against a baseline. |

[Run an Insights query](/reference/insights-run-query) describes every field.

## Example request

This request counts `Sign Up` events per day over the last 30 days:

```bash
curl --request POST \
  --url 'https://mixpanel.com/api/query/insights/query?project_id=YOUR_PROJECT_ID' \
  --user 'YOUR_SERVICE_ACCOUNT_USERNAME:YOUR_SERVICE_ACCOUNT_SECRET' \
  --header 'Content-Type: application/json' \
  --data '{
    "metrics": [
      {
        "type": "event",
        "events": [{"event_type": "event", "name": "Sign Up"}],
        "measurement": {"type": "count", "calculation": "total_events"}
      }
    ],
    "time": {
      "start": {"unit": "day", "value": 30, "align_to_whole_unit": true},
      "unit": "day"
    }
  }'
```

## Limits

A request can have up to 40 metrics, three breakdowns, and 10 filters.
