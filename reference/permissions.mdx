API operations require the caller to hold specific permissions. This page lists
every permission the API checks, the built-in roles that include it, and the custom role
toggle that grants it.

For an overview of roles themselves — how to invite users, assign roles, use teams, and
create custom roles — see [Roles & Permissions](/docs/orgs-and-projects/roles-and-permissions).

## Permissions

A permission scoped to a project is granted by a project role on that project, or by an
organization role across the whole organization.
