The second step in [setting up Mixpanel](/set-up-mixpanel) is implementing your [tracking plan](/set-up-mixpanel/plan-what-to-track) and testing it in a development project.

## Done when

- Events and users are set up correctly
- Your use cases are confirmed
- Data arrives in your development project
